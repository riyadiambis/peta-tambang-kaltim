Alur Kerja Metodologi (5 Fase Pipeline)

1
Pengumpulan Data GEE (L2A Ingestion)

Filter tutupan awan <10%, koreksi atmosfer permukaan Bottom-of-Atmosphere (BOA), serta mosaik komposit median tahunan.

2
Pelabelan Multi-Sumber (Purity ≥ 80%)

Integrasi poligon IUP Minerba 2019, verifikasi ortofoto resolusi tinggi, dan seleksi patch homogen tanpa noise perbatasan.

3
Pelatihan Custom CNN (70 / 15 / 15)

Arsitektur konvolusi multi-spektral dengan spatial dropout dan normalisasi batch guna mencegah overfitting spektral sawit.

4
Prediksi Grid Spasial 640 m

Inferensi serentak pada 4.900 petak grid wilayah Kutai Kartanegara dan koridor tambang aktif Samarinda Utara.

5
Validasi Temporal ESA WorldCover

Uji cross-reference dengan baseline global ESA 10m dengan tingkat kecocokan 95% pada kategori tutupan hutan dan air.

Spesifikasi Model CNN-7B-v2
Input: 64 × 64 × 7 band
Parameter: ~142.800
Framework: TensorFlow / Keras
Optimasi: Adam (lr=0.001)
Batch Size: 32
Epochs: 60 (Early Stop 48)
